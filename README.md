# ashrar-ahmed

Personal site of Ashrar Ahmed, software developer (Flutter & React) in Abu Dhabi.

Vite + React + TypeScript with hand-written CSS. No UI or animation libraries.

## Develop

```bash
npm install
npm run dev
```

Content lives in [src/content.ts](src/content.ts).

## Deploy

Hosted on Cloudflare Workers as static assets ([wrangler.jsonc](wrangler.jsonc)).

```bash
npm run deploy
```
